# Bookese CS — Prototype hỗ trợ booking

[Mở prototype trực tuyến](https://thuongluu2603.github.io/bookese-cs-prototype/)

Prototype cho CS duyệt luồng đặt phòng, tra soát thanh toán, reconfirm, overbooking, đổi/hủy, hoàn tiền và xu; có màn vé, phía khách và xác nhận của khách sạn. Các thao tác chỉ dùng dữ liệu demo lưu trong trình duyệt, không kết nối hệ thống Bookese thật.

Tài liệu yêu cầu Dev và mã nguồn chỉnh sửa được lưu trong bộ bàn giao `Bookese-Customer-Service/Prototype-RQ-Dev-20260924` tại máy làm việc.
